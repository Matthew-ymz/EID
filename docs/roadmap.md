# 维护路线

## 当前：0.1.1 Alpha

- 可本地 pip 安装的独立包。
- 离散二进制 TPM、已知批量响应、已训练模型三种入口。
- EI、Ξ、SPT、统一单位、显式容差、JSON 结果。
- 两组迁移测试、公共接口测试和三个可运行小示例。
- 来源清单与当前论文核对记录。

## 首次公开发布前

1. 使用用户指定的 MIT 许可证、EID 仓库、`eid-toolbox` 发行名和 `eid` 导入名。
2. 在项目实际支持的平台和 Python 版本上运行持续集成。
3. 完成 PyPI Trusted Publisher 配置，发布并检查实际安装。
4. 论文发表时补充正式软件作者、引用信息和手稿版本；当前核对范围与版本不确定性见方法说明。

## 后续小版本

- 时间序列历史构建、按时间切分和通用模型训练/验证接口。
- 仿射 TM 加偏差校正、神经条件 TM 等现有实现的独立抽取。
- 高斯矩约束干预、响应残余协方差、明确的过程噪声接口。
- 变量分组、分组 Ξ 与 Shapley 归因、多预测时距。
- 超图、SPT 和阶数分布的绘图与导出。
- 对较大系统提供预算、缓存复用和不确定性诊断。

每次扩展围绕可验证的输入/输出与示例交付，避免把领域实验依赖引入基础安装。

## 与 EISyn 的关系

核心算法迁移稳定后，让 EISyn 的实验逐项改为调用工具箱。现阶段只是复制抽取，EISyn 尚未切换依赖。论文发表时固定工具箱版本和论文复现提交；后续工具箱修复通过版本发布传递，避免两份核心代码长期独立修改。

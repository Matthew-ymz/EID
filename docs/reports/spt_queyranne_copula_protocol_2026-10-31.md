## 四组控制与估计边界

1. 原文估计方式 + 穷举 SPT，作为直接基线。
2. 同一干预样本、目标和信息查询 + Queyranne：与 1 比较每个节点的分裂目标差、完整层级、信息查询次数和耗时，单独评估搜索算法。
3. Gaussian copula + 穷举 SPT：与 1 比较 EI 估计器与层级恢复，单独评估估计器变化。
4. 同一 Gaussian copula 查询 + Queyranne：与 3 比较，评估新组合。

相位系统严格沿用原文各自的输入分布、完整目标与时间尺度；I 使用共同的 wrapped phase-increment 目标，III 使用共同的 unwrapped future-phase 目标。周期变量的坐标和变换须记录并保持所有方法相同；不能把角度边界或正弦余弦重复坐标产生的秩亏悄悄视为无影响。

II 是二值 Glauber，原文用完整 64 × 64 马尔可夫转移和离散精确 EI；直接对重复的离散数值采用连续 Gaussian copula 及随意加抖动会改变模型。首先在相同完整二元 target 下以精确离散 EI 运行穷举和 Queyranne；如试 Gaussian copula，明确记录 ties 处理、抖动大小和多个随机种子作为近似敏感性实验，与精确离散 EI 比较，不能把它称为无假设的精确替代。

Gaussian copula 数值估计不自动满足精确次模性，也不自动是精确 EI；全程固定一套干预样本和共同目标、同一单位、规范化和正则设置。六节点可穷举全部分裂并直接审计：比较 Queyranne 与穷举最优值及不同树节点，检查次模约束，报告最大违反和数量。所有 Syn 原始值均保留，事先声明以 nats 计的非负容差与容差内负值数；小于负容差则显式报告最小值、阈值、数量并标记失败，不进行截零或把失败解释为负 Syn。每轮记录闭合误差、并列及估计稳定性。

## 重复、成本和输出

尽量复用可核实的正文原始动力学、训练权重、转移矩阵和缓存；不能证实一致时重新模拟并标为重建。三系统至少 3 个配对数据/模拟种子（原始数据/训练种子和估计噪声种子分层记录）。同一实例下共享动力学、通道、共同干预与测试样本；每种结果包含原始模块 F1、完整树及分裂差距。二值 Glauber 还提供解析转移的精确参考。报告恢复次数和跨种子变化，不能以 3 次重复证明普遍稳定。

分别计端到端时间和信息查询/搜索本身的墙钟时间、查询数、缓存状态；对于正文规模 n=6，Queyranne 的额外开销可能抵消查询减少，不预先声称一定更快。准确性指模块恢复、相同估计器下与穷举目标差异，EI 数值误差只在有有效参考时报告；目标误差和 topology 恢复分开。

拟先进行小规模 smoke test，之后完成上述三种系统、配对重复、诊断和图表；建议主运行预算 60 分钟，达到预算保留已有结果并报告缺失，不自动扩展。较轻方案是只复算每种系统各 1 个种子，开销较小，但无法支持稳定性判断，速度比较的偶然性也较大。

用户于 2026-10-31 明确批准方案并指定 Glauber 不采用 Gaussian copula；该系统仅使用离散 EI 对照。已核实正文 Fig. 1 II 使用 48,000 对 MLP 确认缓存，I 的神经 TM 采用分量近似，III 使用弱桥接模型。对可复用缓存分别记录信息表/模型种子及积分随机化，不将同一模型的多次积分称为独立模型复现。预计总运行上限 60 分钟。
